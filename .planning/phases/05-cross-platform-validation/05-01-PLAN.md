<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CI build environment -> production CDN | Build artifacts deployed to public edge; headers must be correct |
| Browser -> Cloudflare CDN | COOP/COEP headers gate SharedArrayBuffer availability |
| rustup.rs install script | curl-pipe-to-sh in CI for Rust installation |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Information Disclosure | Missing COOP/COEP headers | mitigate | public/_headers serves Cross-Origin-Opener-Policy: same-origin + Cross-Origin-Embedder-Policy: require-corp on all routes (/*) |
| T-05-02 | Tampering | WASM binary served without HTTPS | accept | Cloudflare Pages enforces HTTPS automatically; no action needed |
| T-05-03 | Tampering | Stale/cached WASM after deploy | accept | Vite content-hashes WASM filename in import; Cloudflare purges on new deploy |
| T-05-04 | Tampering | curl pipe to sh for rustup install | accept | rustup.rs is the official Rust installer; TLS-only download enforced via --proto '=https' --tlsv1.2; guarded by CF_PAGES env var so does not run locally |
</threat_model>
