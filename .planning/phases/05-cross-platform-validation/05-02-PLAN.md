  <what-built>Plan 05-01 committed build.sh, public/_headers, and rust-toolchain.toml. The checklist (Task 1 above) documents the full verification procedure.</what-built>
  <how-to-verify>
    **Cloudflare Pages Setup (per D-06):**
    1. Go to https://dash.cloudflare.com/ and sign in (or create free account).
    2. Navigate to Workers and Pages > Create > Pages > Connect to Git.
    3. Select this GitHub repository.
    4. Configure build settings:
       - Build command: `sh build.sh`
       - Build output directory: `dist`
       - Root directory: (leave as repo root)
    5. Click "Save and Deploy" to trigger the first build.
    6. Monitor the build log. Expected: Rust installs (~2-5 min), cargo xtask build compiles WASM, npm ci + npm run build produces dist/.
    7. If build succeeds, Cloudflare assigns a `*.pages.dev` URL.

    **Quick Verification (per D-10):**
    8. Open the `*.pages.dev` URL in desktop Chrome.
    9. Open DevTools Console and type `crossOriginIsolated` — should print `true`.
    10. Open Network tab, reload, confirm the WASM file loads (200, not 404).
    11. Press Play, hear clicks at 120 BPM for ~10 seconds.

    **If build fails:** Check the build log for common errors:
    - "source: not found" -> build.sh uses `. "$HOME/.cargo/env"` (should be correct)
    - "wasm-opt not found" -> expected warning, non-fatal
    - Timeout after 20 min -> may need to set `lto = "thin"` in Cargo.toml [profile.release]
  </how-to-verify>
