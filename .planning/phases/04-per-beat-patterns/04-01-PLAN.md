<objective>
Extend the Rust WASM DSP engine with three changes: (1) a voice==2 silent branch in the trigger block so that silent beat events suppress click synthesis, (2) an xorshift32 PRNG and unconditional per-sample noise mixing so that white noise is added to every output frame, and (3) per-sample output clamping to prevent clipping when accent click + 100% noise coincide. Add four cargo tests to verify the new paths.

Purpose: These are the two lowest-level changes in Phase 4. They unblock Plan 04-02 (paramSAB wiring) which depends on the `noise_gain` parameter being functional. The silent voice branch completes the three-entry palette (Normal/Accent/Silent).

Output: rust/src/lib.rs with PRNG_STATE static, xorshift32_next() helper, extended fill_output_buffer, and four new cargo tests.

    Edit rust/src/lib.rs with three distinct changes.

    Change 1 — Add PRNG_STATE static immediately after the existing static block (after ACCENT_AMP):
    Add `static mut PRNG_STATE: u32 = 12345;` — the seed MUST be non-zero (per D-12 and Pitfall 2 in RESEARCH.md). Follow the existing `static mut NAME: TYPE = value;` form exactly.

    Change 2 — Add xorshift32_next() as a private inline helper function, placed before fill_output_buffer. The function must be marked `#[inline(always)]` and `unsafe fn`. It reads PRNG_STATE with `std::ptr::addr_of!(PRNG_STATE).read()`, applies the three-shift Marsaglia xorshift32 triple (shift left 13, shift right 17, shift left 5) via XOR-assign, writes the new state back with `std::ptr::addr_of_mut!(PRNG_STATE).write(state)`, and returns the new state as u32. This is the only PRNG in the file; do not use any rand crate or alternative PRNG.

    Change 3 — Extend fill_output_buffer. Three edit sites inside the function:

    Edit site A — Rename the parameter `_noise_gain: f32` to `noise_gain: f32` (remove the underscore). This parameter currently exists but is unused.

    Edit site B — Inside the trigger block (`if sample_offset != NO_BEAT_SENTINEL`), wrap the existing voice==0/voice==1 logic in an `else` branch under a new `if voice == 2 { }` check. The voice==2 branch is an empty block (no-op) — no ACTIVE set, no envelope trigger. The noise mixing path (edit site C) is OUTSIDE and below the trigger block entirely.

    Edit site C — In the per-sample output loop, replace the direct `ptr.add(i).write(click_sample)` with:
    1. Call `xorshift32_next()` inside an `unsafe` block to get `raw_noise: u32`
    2. Compute `noise_sample = (raw_noise as i32 as f32) / 2147483648.0_f32 * noise_gain`
    3. Compute `mixed = (click_sample + noise_sample).clamp(-1.0_f32, 1.0_f32)`
    4. Write `mixed` via `ptr.add(i).write(mixed)`

    The clamp is mandatory (per RESEARCH.md Pitfall 1) — it prevents clipping when 100% noise and an accent click fire on the same frame. `2147483648.0_f32` is `i32::MAX as f32 + 1` — this normalises the u32 reinterpreted as i32 to [-1.0, 1.0]. Do NOT add a branch `if noise_gain > 0.0` around the PRNG call — per D-12, the PRNG runs unconditionally; the multiplication by 0.0 in IEEE 754 is exactly 0.0.

    After all edits, verify the file compiles: `cargo build --manifest-path rust/Cargo.toml --target wasm32-unknown-unknown`.
