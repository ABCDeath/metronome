    Edit src/lib/pattern.ts — replace the existing rebuildBeats() function with the merge-aware version.

    The new function signature is:
    `export function rebuildBeats(stepCount: number, existingBeats?: BeatPosition[]): BeatPosition[]`

    The body has two branches:
    - If existingBeats is not provided (undefined/falsy): return the Phase 3 default exactly as before — `Array.from({ length: stepCount }, (_, i) => ({ voice: i === 0 ? 1 : 0 }))`. Beat 0 gets voice 1 (Accent), all others voice 0 (Normal). This preserves D-06 default behavior.
    - If existingBeats IS provided: return `Array.from({ length: stepCount }, (_, i) => ({ voice: i < existingBeats.length ? existingBeats[i].voice : 0 }))`. This copies voice assignments for positions that still exist, and fills new positions beyond existingBeats.length with Normal (voice 0). Note: when stepCount < existingBeats.length, Array.from only generates stepCount elements — the extra entries are implicitly truncated (no explicit slice needed).

    No other changes to pattern.ts. The TypeScript type signature change is backwards-compatible — all existing callers that pass only stepCount continue to work without modification.

  </action>
