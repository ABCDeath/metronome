    Add imports at top of script: import type { PatternState, Subdivision } from './lib/pattern.js' and import { SUBDIV_MULT, rebuildBeats, defaultPatternState } from './lib/pattern.js'.

    Add reactive state declarations after the existing engineState declaration:
    - let pattern = $state<PatternState>(defaultPatternState())
    - let numerator = $state(4) — tracks the time signature numerator separately for the input
    - let accentPitchOn = $state(true) — D-02: pitch toggle default on
    - let accentAmpOn = $state(true) — D-03: amplitude toggle default on
    - let accentAmpValue = $state(1.3) — D-03: default 1.3x

    Add $effect binding after the engine construction:
    $effect(() => { engine.updatePattern(pattern) })

    Add helper functions:

    adjustBpm(delta: number): pattern.bpm = Math.max(20, Math.min(300, pattern.bpm + delta))

    onBpmInput(e: Event): parse integer from input value, if valid and in [20,300] set pattern.bpm, otherwise revert input to pattern.bpm. On blur and on Enter keypress.

    onBpmSlider(e: Event): parse integer from range input value, set pattern.bpm directly (already clamped by range min/max).

    onTimeSigChange(): compute stepCount = numerator * SUBDIV_MULT[pattern.tracks[0].subdivision], then set pattern.tracks[0].stepCount = stepCount, pattern.tracks[0].beats = rebuildBeats(stepCount). Called when numerator, denominator, or subdivision changes.

    onNumeratorInput(e: Event): parse integer, clamp to [1,12], set numerator, set pattern.tracks[0].stepCount and denominator, call beat rebuild.

    onDenominatorChange(e: Event): parse integer from select value, set pattern.tracks[0].denominator, recompute stepCount and rebuild beats.

    onSubdivisionChange(subdiv: Subdivision): set pattern.tracks[0].subdivision = subdiv, recompute stepCount = numerator * SUBDIV_MULT[subdiv], set pattern.tracks[0].stepCount, rebuild beats.

    updateAccentParams(): compute accentFreqHz = accentPitchOn ? 1400 : 1000, accentAmpMillis = accentAmpOn ? Math.round(accentAmpValue * 1000) : 1000, set pattern.accentFreqHz and pattern.accentAmpMillis.

    Add a second $effect for accent params: $effect(() => { updateAccentParams() }) — this tracks accentPitchOn, accentAmpOn, accentAmpValue reads and updates pattern.

    In handlePlayStop, after engine.start(), call engine.updatePattern(pattern) to ensure accent params are written to paramSAB after SAB initialization (Pitfall P3-04 safety).
