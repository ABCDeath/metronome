## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Main thread -> AudioWorklet (via SAB) | Scheduler writes u32 events; worklet reads them. Data crosses thread boundary via SharedArrayBuffer. |
| AudioWorklet -> WASM FFI | Worklet passes sample_offset, voice, noise_gain to WASM exports. |
| User gesture -> AudioContext | Play button click gates AudioContext creation (D-12). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-03 | Denial of Service | Ring buffer overflow | mitigate | Drop-if-full check: nextWrite !== readIdx before writing. At 120 BPM, ring accumulates ~1 event/500ms; 256-slot ring holds ~128 seconds of headroom. |
| T-02-04 | Tampering | Stale quantum events after stop/start | mitigate | Ring indices reset to 0 via Atomics.store in stop(); nextBeatTime re-seeded to audioCtx.currentTime in start(). |
| T-02-05 | Information Disclosure | process() allocation (GC timing side channel) | mitigate | Zero allocations enforced: no new, no object literals, no string ops inside process(). Code review + DevTools Memory tab verification. |
| T-02-06 | Denial of Service | nextBeatTime = 0 floods ring | mitigate | nextBeatTime seeded to audioCtx.currentTime on start(), never to 0 (RESEARCH.md Pitfall 2). |
| T-02-SC | Tampering | npm/pip/cargo installs | accept | No new packages installed in this plan. |
</threat_model>
