  <action>
    Create public/worklet/processor.js as a plain JavaScript file (NOT processed by Vite). Per D-07, D-08.

    The MetronomeProcessor class extends AudioWorkletProcessor:

    constructor(options):
    - Extract wasmModule from options.processorOptions
    - Set this._ready = false
    - Call WebAssembly.instantiate(wasmModule, {}).then(callback) where the callback:
      - Stores instance.exports as this._exports
      - Calls this._exports.init(sampleRate) — sampleRate is a global in AudioWorkletGlobalScope, read it directly (do NOT pass via processorOptions). Per CONTEXT.md constraint.
      - Calls this._exports.get_output_buffer_ptr() to get the pointer
      - Creates this._outputView = new Float32Array(instance.exports.memory.buffer, ptr, 128) — created ONCE, never recreated. Per D-11.
      - Sets this._ready = true
      - Posts { type: "ready" } via this.port.postMessage

    Set up this.port.onmessage handler for "init-buffers" message type:
    - Receives controlRing (SharedArrayBuffer) and paramBuffer (SharedArrayBuffer)
    - Creates this._ringIndices = new Int32Array(controlRing, 0, 2) (read/write indices)
    - Creates this._ringData = new Uint32Array(controlRing, 8, 256) (beat event slots, offset 8 to align after 2 x Int32)
    - Creates this._paramBuffer = new Int32Array(paramBuffer, 0, 8)
    - These typed array views are created ONCE at init. Per D-11.

    process(inputs, outputs):
    - If !this._ready, return true (keep alive while WASM loads)
    - Call this._exports.fill_output_buffer(0, 0.0) — Phase 1 passes zeros (no beats, no noise)
    - Copy: outputs[0][0].set(this._outputView) — copies 128 f32 from WASM memory to output
    - return true (MUST return true to keep processor alive)
    - NO allocations inside process(): no new, no object literals, no string operations

    Call registerProcessor("metronome-processor", MetronomeProcessor) at module level.

    Create src/lib/audio-engine.ts as a TypeScript class AudioEngine with:

    Private fields: audioCtx (AudioContext | null), workletNode (AudioWorkletNode | null), controlRingSAB (SharedArrayBuffer | null), paramSAB (SharedArrayBuffer | null), _state ("stopped" | "running"), onStateChange callback.

    Constructor: set all to null/defaults. Accept optional onStateChange: (state: string) => void callback.

    async start() method:
    - If _state is "running", return (idempotent)
    - Create AudioContext with latencyHint: "interactive" if not exists. Per D-12 — this is called from a click handler, satisfying the gesture gate.
    - If audioCtx.state is "suspended", await audioCtx.resume(). Per D-12.
    - If workletNode is null (first start):
      - Fetch /wasm/metronome_engine_bg.wasm, get arrayBuffer, call WebAssembly.compile(buffer). Per D-07.
      - Await audioCtx.audioWorklet.addModule("/worklet/processor.js")
      - Allocate controlRingSAB: new SharedArrayBuffer(4 + 4 + 256 * 4) — 2x4 bytes for Int32 indices + 256x4 bytes for Uint32 events = 1032 bytes
      - Allocate paramSAB: new SharedArrayBuffer(8 * 4) — 8 Int32 parameter slots = 32 bytes
      - Create AudioWorkletNode with processorOptions: { wasmModule }, numberOfInputs: 0, numberOfOutputs: 1, outputChannelCount: [1]
      - Post { type: "init-buffers", controlRing: controlRingSAB, paramBuffer: paramSAB } via workletNode.port.postMessage. Per D-11.
      - Set workletNode.port.onmessage to handle { type: "ready" } — log "AudioWorklet ready" and crossOriginIsolated value
      - Connect workletNode to audioCtx.destination
    - Set _state = "running", call onStateChange

    async stop() method:
    - If _state is "stopped", return
    - Await audioCtx.suspend()
    - Set _state = "stopped", call onStateChange

    get state() getter: returns _state

    Export AudioEngine as named export.
  </action>
