    Create rust/src/lib.rs with three #[no_mangle] pub extern "C" fn exports. Per D-08:
    - get_output_buffer_ptr() -> *const f32: returns pointer to static mut AUDIO_OUT: [f32; 128]
    - fill_output_buffer(beat_flags: u32, noise_gain: f32): fills AUDIO_OUT with 0.0 (silence)
    - init(sample_rate: f32): stores sample_rate in static mut SAMPLE_RATE (default 44100.0)
    The static mut AUDIO_OUT array is the zero-allocation output buffer. No heap allocations, no Vec, no String. Per D-11.

    Create xtask/Cargo.toml: package name = "xtask", edition = "2021", [[bin]] name = "xtask" path = "src/main.rs", dependencies: clap = { version = "4", features = ["derive"] }, xtask-watch = "0.3". Per D-04.

    Create xtask/src/main.rs implementing three subcommands via clap derive. Per D-05, D-06:
    - BuildWasm: calls build_wasm() function
    - Build: alias for BuildWasm (same function)
    - Dev: spawns npm run dev as child process via std::process::Command, then uses xtask_watch to watch rust/src/ directory and re-run build_wasm() on changes

    The build_wasm() function executes four steps sequentially, each checking exit status. Per D-06, D-09:
    Step 1: Command::new(env!("CARGO")).args(["build", "--release", "--target", "wasm32-unknown-unknown", "--manifest-path", "rust/Cargo.toml"])
    Step 2: Command::new("wasm-bindgen").args(["--target", "web", "target/wasm32-unknown-unknown/release/metronome_engine.wasm", "--out-dir", "rust/pkg"])
    Step 3: Command::new("wasm-opt").args(["-O3", "rust/pkg/metronome_engine_bg.wasm", "-o", "rust/pkg/metronome_engine_bg.wasm"])
    Step 4: std::fs::create_dir_all("public/wasm") then std::fs::copy("rust/pkg/metronome_engine_bg.wasm", "public/wasm/metronome_engine_bg.wasm")

    Use env!("CARGO") for the cargo binary path (not hardcoded "cargo"). Print each step to stderr for visibility. If wasm-opt is not found, print a warning and skip (Phase 1 silence module is tiny; optimization is optional for dev).

    Create public/wasm/.gitkeep as empty file so the directory is tracked.
  </action>
